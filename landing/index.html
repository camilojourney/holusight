camilojourney/holusight

Hybrid BM25 + vector search with reciprocal rank fusion.
Index documents and code locally - ask questions, get cited answers.

Hybrid Retrieval

BM25 keyword search fused with dense vectors via RRF. Catches exact terms and semantic matches.

Documents & Code

PDF, Word, PowerPoint, markdown, and source files - one index, AST-aware chunking for code.

Local-First

Indexes live on your machine. Your files never leave your environment unless you choose a cloud LLM.

Source Citations

Every answer links back to the exact chunk, file, and line range that supported it.

Try it locally

pip install -e ".[dev,demo]"
python -m codesight index ./your-docs
python -m codesight search "payment terms" ./your-docs
python -m codesight demo
