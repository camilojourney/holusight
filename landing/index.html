Holusight

A read-only consistency helper for agents. Compare an existing Graphify graph to its repository to find broken references, missing source paths and stale provenance. No document search, model calls, or automatic graph rebuild.

uv run --offline python -m holusight check /path/to/repo

Results distinguish current, stale, unknown, and unavailable. Agents inspect cited source for proof; graph edges alone cannot verify prose.
